Sprint 3 — vW3 — Automate the Manual Process

Last week you did it all by hand — sixteen lookups, sector math, macro notes, seasonality. This week your job is to make the computer do at least one part of that for you.

The Sprint Goal

Replace at least one manual Sprint 2 task with a working automation — a script, scheduled job, or simple bot that fetches or calculates that same data without you typing it in by hand.

It doesn't need to be polished. It needs to run, and it needs to save you the exact pain you felt last week.

The Backlog — Pick Your Automation Target

1Technical: automate the OHLC pull

Write a script that fetches weekly OHLC for some or all of the 16 instruments from Sprint 2 (SPX, NDX, 10-year yield, gold, Bitcoin, 11 sector ETFs) — via an API or library instead of manually reading Yahoo Finance.

DONE MEANS — running code, committed to your team repo, that outputs the same data you gathered by hand in Sprint 2, for at least 5 of the 16 instruments.
2Macro: automate the sector comparison

Script the weekly % change calculation and the "beat or lagged vs. SPX" comparison from Sprint 2, so it recalculates automatically once new price data comes in.

DONE MEANS — code that takes price data and outputs which sectors beat/lagged SPX, with no manual math.
3Reflection: manual vs. automated

Write 150–250 words comparing the two experiences — what took longer to automate than expected, what broke, what you'd automate next if you had another week.

DONE MEANS — reflection committed as reports/vW3.md in your team repo.

Then: Write It Up and Present

Bring your working automation and reflection to Monday's session. Be ready to run it live or show output — not just describe it.

Presentation Order

Team 2 → Team 3 → Team 4 → Team 5 → Team 1 — order rotates each sprint so the same team isn't always last.
Real deadline: Sunday night, not Monday morning. Code and reflection committed by Sunday. Monday is presentation day, not build day.

What Monday Actually Is

Sprint Review of what you automated, plus Sprint 4 Planning. Come having done the work.
